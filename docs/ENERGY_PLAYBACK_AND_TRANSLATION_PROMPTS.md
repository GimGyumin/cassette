# 발열·재생 복구·번역 프롬프트 변경 — 2026-10-11

사용자 보고: iPhone에서 불규칙하게 발생하는 발열/배터리 소모, 재생 도중 처음으로 돌아감, 재생 버튼을 눌러도 소리가 시작되지 않음. 기존 작업 폴더의 변경을 보존한 상태에서 공통 재생·화면·번역 경로를 수정했다.

## 재생

- 곡 중간의 미디어 시계 초기화를 정상 EOF와 구분한다. 탐색 중이거나 확인된 gapless 전환이면 복구를 시작하지 않는다. 예기치 않은 초기화는 직전 위치에서 한 번 복구하며, 반복 실패는 위치를 보관한 오류로 끝낸다.
- AVPlayer 실패 항목은 그대로 resume하지 않는다. 원격 소스를 한 번 갱신하고, 수동 재시도와 시스템 인터럽트 복귀에서도 위치를 유지하며 엔진을 연다. 이미 다운로드된 유효 파일은 서버 재협상을 기다리지 않는다.
- 늦게 끝난 resume/복구가 이후의 pause, stop, seek, 곡·라디오 선택을 덮어쓰지 않도록 명령 번호와 재생 세대를 확인한다. 네트워크 준비 중에도 대기 상태를 표시해 다시 눌러 취소할 수 있다.
- 화면 복귀 시 상태 점검은 점검 도중 사용자가 수행한 탐색을 이전 위치로 되돌리지 않는다. 네이티브 복원 seek가 완료되기 전의 0초는 UI/EOF 판정에 사용하지 않는다.
- 진행 시간 루프 자신이 복구를 시작해 타이머를 취소하는 경우도 검증한다. 해당 취소로 복구 엔진 시작이 누락되지 않도록 했다.

## 전력 사용

- 가사 시계는 단어 가사 30 Hz, 줄 가사 10 Hz로 제한한다. 발열 `fair` 또는 절전 상태에서는 각각 20 Hz / 약 6.7 Hz로 낮춘다. 숨겨진 가사 화면은 기존과 같이 추적을 중지한다.
- `fair` 단계부터 배경 GPU 효과를 15 → 8 fps, 오디오 표시 갱신을 20 → 10 Hz로 낮추고 무거운 커버 색 분석과 자동 번역을 미룬다. 사용자가 직접 요청한 번역은 가능하다.
- 절전/백그라운드 재생 감시는 1초 간격과 타이머 허용 오차를 사용한다. 재생과 다음 곡 준비는 유지한다.
- 공통 mesh 배경에 프레임 상한을 적용하고, 로딩 pulse/shimmer는 화면 이탈·백그라운드·동작 줄이기·절전·심한 발열에서 중지한다.

## 번역 프롬프트

설정 → 가사 및 번역 → Apple Intelligence 번역 프롬프트에서 편집, 저장, 기본 번역 복원이 가능하다. 저장은 입력 완료 후 수행하며, 1,000자 제한과 한국어 안내를 제공한다.

Apple Translation의 `TranslationSession.Request`에는 사용자 프롬프트 인자가 없다. 저장된 프롬프트가 있으면 [Foundation Models의 LanguageModelSession](https://developer.apple.com/documentation/foundationmodels/languagemodelsession)을 사용한다. iOS/macOS 26 이상에서 Apple Intelligence 온디바이스 모델이 준비되어야 한다. 프롬프트가 비어 있으면 기존 Translation 전략을 사용한다.

중복 가사를 제거하고 최대 6줄/1,200자 단위로 순차 번역한다. 각 묶음에 새 모델 세션을 사용해 문맥 누적을 제한하고, 출력 개수와 빈 결과를 검사한 뒤 원래 줄 순서와 코러스에 배치한다. 모델을 사용할 수 없으면 이유와 기본 번역으로 돌아가는 방법을 표시한다. 저장된 프롬프트를 조용히 무시하는 대체 번역은 하지 않는다.

캐시는 프롬프트의 지문을 포함해 구분한다. 기존 기본 번역 캐시는 유지하며, 설정 변경 시 진행 중 요청과 메모리에 남은 이전 클라이언트 번역을 무효화한다.

## 검증 범위

회귀 테스트는 실제 로컬 오디오의 중간 위치 복원, 진행 시간 루프에서의 복구, 반복 복구 제한, 늦은 resume와 pause/stop 경합, 변경된 프롬프트의 캐시 분리 및 이전 번역 폐기를 다룬다.

실제 AAC 탐색 테스트에서 seek 완료와 오디오 시작 콜백 사이의 정상적인 대기 구간을 즉시 실패로 판단하던 경합을 발견했다. 재생 확인 조건은 유지하고, 오디오 시작을 최대 2초까지 기다리도록 수정했다.
