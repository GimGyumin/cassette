# 1029 가사·재생 전환·자동 저장 수정

## 확인한 원인과 변경

- 가사 컨트롤은 4.5초 후에도 다음 가사 줄 변경을 기다렸다. 이제 줄 변경·재생 여부와 관계없이 비활동 시간으로 숨긴다. 세로 플레이어의 번역/하단 버튼, 가로 플레이어의 하단/번역 버튼, 넓은 화면의 하단 버튼에 동일한 숨김 상태를 연결했다. 숨긴 버튼은 터치와 접근성 탐색에서도 제외하고, 가사를 터치하거나 스크롤하면 다시 표시한다. 가로 가사 패널에도 상호작용 콜백을 연결했다.
- 새 곡 선택을 접수한 뒤 실제 음원을 교체하기 전의 비동기 구간에 이전 곡의 종료/미리 준비된 다음 곡 이벤트가 개입할 수 있었다. 선택 중인 명령을 표시하여 자동 전환을 차단하고, 중단 지점 이후에도 명령/epoch를 검증한다. 동시에 접수된 선택은 최신 요청을 우선한다.
- 대기 상태에서 seek 또는 버퍼 시계가 이동한 것만으로 재생 시작을 확정할 수 있었다. 실제 엔진이 playing인 경우에만 확정한다. 정상적으로 이어진 곡에도 시작 복구 감시를 예약한다. 처음 수 초 만에 끝난 원본 스트림도 조기 종료로 처리하여 선택한 곡을 유지한다.
- 자동 저장은 백그라운드와 가벼운 발열에서도 차단되었다. 사용자가 켠 자동 다운로드/캐시는 화면이 꺼진 재생에서도 가능하도록 했다. 저전력 모드·심한 발열·메모리 압박에서는 계속 보류한다.
- AVPlayer의 Wi-Fi 전방 버퍼 목표가 10초인데 자동 저장도 최소 10초를 요구했다. 소비 중인 버퍼가 이 경계에 도달하지 못할 수 있어, 5초간 실제 재생 시계가 진행된 뒤 기존의 안전한 버퍼 여유 정책으로 저장을 시작한다.
- 캐시 예약이 새 엔진 시작 경로에만 있어 gapless로 넘어간 곡은 저장되지 않았다. 공통 예약 함수를 일반 시작, gapless, 재시도 경로에 연결했다. 자동 다운로드 설정이 켜져 있다는 사실만으로 캐시를 차단하지 않고, 실제 예약/진행 중인 영구 저장과 중복되지 않도록 한다.
- 무선 오디오 출력이라는 이유만으로 캐시를 막던 조건을 제거했다. 셀룰러 캐시 허용 설정을 반영하고, 고해상도 스테레오/채널 정보가 없는 FLAC의 native 재생 필요성과 캐시 금지 정책을 분리했다. Dolby/멀티채널과 모호한 MP4의 비트스트림 보호는 유지한다. HLS/Universal 응답은 단일 오디오 파일 캐시로 저장하지 않는다.
- 캐시 전체 전송 제한을 30초에서 300초로 늘리고, URLSession의 별도 디스크 캐시를 비활성화했다. 실패한 캐시 전송도 기존 자동 저장 재시도 정책으로 최대 3회, 지연을 두고 시도한다. 완료된 영구 다운로드에는 매번 재생 안정성 감시를 다시 만들지 않는다.
- Dolby 대체 음원을 듣다가 손실 압축 형식으로 자동 저장할 때는, 가능한 경우 앨범의 원래 곡을 저장하여 오프라인 앨범 재생에서 사용할 수 있게 했다.

## 셀룰러 Dolby 설정

설정의 Dolby Atmos 화면에 **Allow Dolby Atmos over Cellular / 셀룰러에서 Dolby Atmos 허용**을 추가했다. 기존 동작을 보존하도록 기본값은 허용이며, 끄면 다음 곡부터 적용된다.

- 대체 Dolby 음원의 원격 재생이 제한되면 원래 곡으로 돌아간다.
- Dolby 음원만 있는 곡은 Wi-Fi 또는 다운로드한 원본이 필요하다는 오류를 표시한다.
- 다운로드한 Dolby 원본은 셀룰러에서도 재생한다.
- Wi-Fi에서 준비한 다음 곡이 셀룰러로 전환된 뒤 제한을 우회하지 않도록 준비 상태를 무효화한다.
- Dolby 판정과 모호한 MP4/일반 멀티채널 판정을 구분하여 일반 음원을 잘못 차단하지 않는다.

## 애니메이션과 배터리

플레이어를 닫은 뒤 지연 작업이 배경 애니메이션을 다시 활성화하지 못하도록 작업을 취소한다. 가사·큐·회전·백그라운드 및 전체 플레이어 뒤에 가려진 미니플레이어에서는 제목 스크롤을 중지한다. 제목 스크롤이 중지될 때 이미 실행 중인 위치 애니메이션도 애니메이션 없는 transaction으로 정리한다. 기존 화면 전환 효과 전체를 제거하지 않았다.

첨부 파일은 원시 로그가 아닌 분석 요약이다. `cannot add handler to 0 from 0`, `glassEffect()` 및 문자열 `onChange` 경고의 정확한 호출 지점은 이번 자료만으로 확정하지 않았다. 기존 세션 저장의 주기 제한/중복 저장 방지를 유지했다. 장시간 배터리 사용량, 디스크 쓰기량 및 시스템 경고 소멸 여부는 실제 기기의 Instruments/새 로그로 확인해야 한다.

## 검증

- 최종 iOS Simulator 대상 앱 빌드 성공.
- 최종 회귀 테스트 169개 실행 케이스 통과, 실패 0개. macOS에서 실제 native/AudioStreaming 연속 재생, 선택/중단/seek 회귀, 다운로드 복원, 전송 중복 조정, 계정별 세션 저장, 성능 정책 테스트.
- 추가 회귀: 셀룰러 Dolby 대체/단독/다운로드 경로, 일반 MP4 오분류 방지, 고해상도 스테레오 캐시 허용, 대기 시계의 잘못된 재생 확정 방지, 선택 중 이전 EOF 무시, 원본 스트림 조기 종료 시 선택 유지.
- iPhone 실기기에서 가로/세로 가사 버튼 숨김, 장시간 배터리 및 셀룰러 전환은 별도 확인이 필요하다.
