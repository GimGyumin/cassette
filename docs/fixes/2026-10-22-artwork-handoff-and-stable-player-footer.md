# 몰입형 앨범과 플레이어 연결 — 1028

## 앨범 페이지

제공된 두 장 중 1번 Apple Music 화면을 기준으로 커버와 제목의 위치를 분리했다. 실제 윈도 안전 영역이 있는 앨범 페이지에서 비사진형 커버는 정사각형 크기를 유지하면서 0.075w만큼 아래로 이동하고, 제목 시작점은 0.06w만큼 위로 이동한다. 제목과 아티스트의 검은 텍스트 그림자를 제거했다. 제목 줄 수와 동적 글자 크기는 실제 텍스트 높이로 계산하며 기존 스크롤 연동 블러/페이드는 유지한다.

설명, 장르, 음질 표시는 앱의 실제 데이터에 따른다. 참고 화면에 없는 설명이나 다른 음질 정보를 특정 앨범 이름에 맞춰 숨기지 않았다.

## 본문 색상과 캐시

분석기 v10은 하단 중앙 밴드와 본문 색상의 연속성을 함께 판단한다. 하단이 회색 또는 옅은 색이면 내부 인물/의상의 강한 색보다 해당 하단 색조를 우선한다. 하단의 좁은 유색 필드가 내부의 큰 색상 필드와 반대 색상일 때도 하단을 따른다. 검은 테두리 우선 처리와 기존의 흰 타이포그래피/붉은 필드/남색 필드 처리를 유지한다.

버전 9 이하 캐시 및 필수 정보가 부족한 캐시는 기존 실행 시 라이브러리 준비와 앨범 진입 시 준비 경로에서 다시 분석된다. 뷰에서 이미지 전체를 재분석하지 않는다.

## 재생 중 화면

원본 하단과 연장 영역의 혼합 범위를 18%에서 28%로 넓히고 비선형 마스크를 사용한다. 연장 영역 전체를 먼저 어둡게 하던 처리를 커버 인계 이후의 점진적인 어둡기로 바꿔 경계 내부의 어두운 띠를 줄였다. 실제 하단 밝기에 맞춘 컨트롤 스크림으로 밝은 커버에서도 글자 대비를 유지한다. 연장은 계속 하단 가장자리 픽셀만 사용하므로 얼굴의 색이나 커버 중앙이 하단으로 늘어나지 않는다.

세로 화면의 가사·출력·큐 메뉴는 각 화면 내부에서 제거하고 하나의 공통 오버레이에 둔다. 윈도 안전 영역을 포함한 동일 좌표, 54pt 슬롯, 20pt 글리프를 사용하며 선택 원도 54pt로 고정한다. 가사 전체 보기의 자동 크롬 숨김과 터치 차단은 유지한다. 표준 보기 및 큰 접근성 글자 크기는 기존 콘텐츠 레이아웃을 유지한다.
