# 단색 앨범 커버 스크롤 경계선

사용자 사진의 상단 커버와 제목 영역 사이 가로선을 갈색 단색 커버로 재현했다.
`FadedArtworkHero`에서 원본과 블러 이미지를 각각 `1 - blur`, `blur`로 표시하면
source-over 합성의 불투명도가 중간 구간에서 0.75로 내려간다. 이때 커버 뒤의
상단 색상과 하단 연장 사각형의 끝이 가로 경계선으로 드러났다.

원본 이미지를 불투명하게 유지하고 블러 이미지만 덮어씌우도록 변경했다.
이미지 전환과 마스크, 연장 색상을 그룹으로 합성한 뒤 전체 스크롤 페이드를 적용한다.
제목·버튼을 가리는 방식으로 처리하지 않고 배경 합성에서 원인을 제거했다.

검증:

- 같은 갈색 커버를 스크롤 거리 0/120/180/220/260/310/360에서 이미지로 렌더링.
- 좌우 세 열의 인접 픽셀 밝기 차이를 검사해 갑작스러운 가로 색상 변화 검출.
- 수정 전 7개 구간 중 4개 실패, 수정 후 모두 통과.
- 기존 커버 표시와 스크롤 진행률을 포함한 테스트 41회 통과, 실패 0.
- 수정 전·후 PNG를 직접 비교해 경계선 제거 확인.
- iOS Simulator 범용 빌드 및 git diff --check 통과.
- 실기기 설치 검증은 수행하지 않았다.
