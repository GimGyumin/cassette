# 앨범 페이지 하단 배경색 복귀 수정

`More by Artist`의 어두운 배경이 목록의 실제 콘텐츠 높이까지만 적용돼,
시스템 미니플레이어와 탭 바의 하단 안전 영역에서는 원래 페이지 색이 드러났다.

목록의 bounds anchor를 페이지 배경에서 읽어 해당 영역의 시작부터 화면 하단까지
동일한 색상으로 채우도록 변경했다. 하단 안전 영역을 포함하며, 스크롤 위치를
별도 페이지 상태로 발행하지 않는다. 목록 자체와 하단 연장 영역은 같은
`AlbumRelatedShelfFill`을 사용한다. 테마가 없는 경우에도 불투명 시스템 배경을
기준으로 삼아 겹친 레이어가 더 어두워지는 일을 방지한다.

관련 앨범이 없거나 목록 시작이 화면 밖 아래에 있으면 하단 색상을 바꾸지 않는다.
넓은 화면에서는 anchor의 가로 범위만 채워 사이드바까지 확장되지 않게 했다.

검증:

- 목록 없음, 화면 위로 이동, 화면 내부의 두 위치, 화면 아래 위치의 5개 렌더링 검사.
- 미니플레이어·탭 바를 가정한 120pt 안전 영역을 포함해 실제 픽셀 색상 비교.
- 스크롤 진행률 테스트 포함 6회 통과, 실패 0.
- 렌더링 PNG에서 하단까지 색상이 이어짐을 직접 확인.
- iOS Simulator 범용 빌드 및 git diff --check 통과.
- 실기기 설치 검증은 수행하지 않았다.
