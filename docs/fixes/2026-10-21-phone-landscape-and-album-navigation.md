# 아이폰 가로 재생 화면과 앨범 탐색 — 1019

## 변경

- 아이폰의 compact-height 가로 방향에서 전용 두 열 배치를 사용한다. 왼쪽은 고정된 정사각형 커버, 오른쪽은 곡 정보·즐겨찾기·더 보기와 재생/가사/대기열이다. 가사와 대기열 전환 시 커버 크기는 유지한다.
- 오른쪽 하단에 가사·출력 장치·대기열 버튼을 유지한다. 재생 위치, 재생/정지, 이전/다음 곡, 시스템 볼륨, 가사 탐색, 대기열 이동은 기존 서비스와 연결한다. 새로운 재생 상태를 만들지 않는다.
- 안전 영역 안에서 너비와 높이에 맞춰 커버를 배치한다. 작은 화면에서는 재생 버튼 간격을 줄이고 컨트롤 영역을 스크롤할 수 있게 한다. 가로 화면에서 출력 장치 이름이 바닥 밖으로 나오지 않도록 이름 표시는 생략한다.
- 공유/더 보기 버튼은 모두 44pt 영역, 20pt 아이콘으로 맞춘다. 공유 아이콘에 앨범 아티스트용 동적 글꼴을 적용하던 설정을 제거했다.
- 앨범 카드에서 들어가는 탐색은 줌 대신 시스템 기본 push/pop을 사용한다. 재활용될 수 있는 lazy 카드의 matched source를 닫기 전환에서 참조하지 않는다. 앨범 route identity와 기존 NavigationPath는 유지한다. 닫기를 지연시키는 타이머는 추가하지 않았다.

## 범위와 확인

- 출력 장치 목록은 기존 `AVRoutePickerView`가 제공하는 실제 시스템 선택기다. 첨부 이미지의 커버를 포함한 Apple Music 전용 출력 패널을 복제하지 않는다.
- 현재 제공되는 즐겨찾기/공유/다운로드/플레이리스트/앨범 이동 메뉴를 재사용한다. 사진에 보이는 Apple Music 전용 기능을 동작하지 않는 버튼으로 추가하지 않는다.
- iOS Simulator 대상 빌드 성공(경고·오류 없음). macOS 테스트 9개 통과: 네 가지 가로 안전 영역 크기의 렌더링에서 커버 비율·열 간격·양쪽 여백·컨트롤 최소 너비를 확인하고, 기존 가사·테마 복원 회귀 테스트를 실행했다. `git diff --check`도 통과했다.
- 실제 iPhone에서 회전, 연결 장치 선택기, 인터랙티브 뒤로 가기와 보고된 닫기 지연은 아직 검증하지 못했다. 줌 전환 제거는 해당 경로에 대한 수정이며, 기기에서 원인을 확정한 결과는 아니다.
