# AMLL 동적 배경 적용

사용자가 지정한 [AMLL 배경 가이드](https://amll.dev/guides/component/background)와
로컬 `applemusic-like-lyrics`의 `packages/core/src/bg-render/pixi-renderer.ts`
(커밋 `5fee356362353dbb24ce9bea3a62536478040de7`)를 기준으로 작업했다.

## 적용

- `AMLLArtworkMotion.swift`: Pixi의 네 앨범 이미지 레이어의 크기, 회전 방향·속도,
  중심 위치와 궤도 계산을 Swift로 이식했다. ticker delta를 초 단위로 환산해
  렌더링 프레임률과 무관하게 같은 속도로 움직인다.
- `LyricsArtwork.metal`: Swift에서 전달한 네 레이어를 순서대로 합성하고,
  기존 Metal Gaussian blur·색 관리·톤 매핑으로 넓고 부드러운 색 영역을 만든다.
  가로·세로 모두 화면의 긴 변을 기준으로 계산해 이미지 레이어가 찌그러지지 않는다.
- 원본의 무작위 초기 회전 대신 고정 회전을 사용해 같은 시각의 출력이 안정적이다.
  약한 좌표 왜곡과 밝기 조정은 기존 네이티브 구현을 사용한다.
  Pixi/WebGL 전체 또는 MeshGradientRenderer를 그대로 실행하는 구현은 아니다.
- 기존 `AppleMusicLyricsBackground`에 연결되어 가사 화면과 해당 배경을 공유하는
  플레이어 화면에 적용된다. 선명한 앨범 커버를 표시하는 몰입형 화면은 기존 구성을 따른다.
- 앨범 변경 시 현재 합성 결과에서 1.2초간 전환한다. 전환 도중 다음 앨범이 들어와도
  현재 보이는 색에서 이어진다.
- 배경은 오디오 탐색 시각과 독립된 누적 시계를 사용한다. 일시정지·화면 숨김·앱 비활성 시
  정지하고 재개 시 이어진다. 저전력, 동작 줄이기, 발열 및 메모리 압박 정책을 유지한다.
- 긴 변 최대 384px, 정상 상태 15fps의 기존 렌더링 예산과 텍스처 캐시를 재사용한다.
  오디오 분석, 상시 SwiftUI 타이머, 새로운 네트워크 다운로드는 추가하지 않았다.
- 앨범 이미지를 이용하는 배경이다. 앨범 비디오를 배경 텍스처로 공급하는 기능은 이번 범위에 포함하지 않았다.
- 사용자의 마지막 요청에 따라 가사 글로우 코드는 수정하지 않았다.

## 검증

- 배경 및 전력 정책 테스트 **25회 통과**, 실패 0.
- 실제 Metal 출력에서 0초/6초/90초 색 영역 변화, 같은 시각의 결정적 출력,
  flowSpeed 0에서 정지한 출력 확인. 가로·세로 모두 검사했다.
- Pixi 기준 레이어 좌표·각도, 속도 배율, 일시정지 시계, 빠른 연속 앨범 전환,
  중립/밝은/어두운 이미지의 색과 가독성, 텍스처 캐시 재사용 검사 포함.
- 합성 앨범 이미지의 가로·세로 PNG를 직접 확인했다.
- 선택적 실제 앨범 프리뷰 테스트는 로컬 이미지가 없어 건너뛰었다.
- iOS Simulator 범용 빌드 성공. 컴파일 경고·오류 없음.
- 실기기 설치 및 전력 측정은 수행하지 않았다.
