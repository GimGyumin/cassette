# 상단 블러 조건과 커버 경계 — 1017

## 비교 사진에서 확인한 문제

사용자가 새로 보낸 Number Ones·Thriller·The Original Master Collection의 실제 화면에서는 얼굴/인쇄 문자가 상단 효과에 가려졌다. Number Ones에는 원본 이미지가 끝나는 가로선과 빨간 인쇄 요소가 아래로 반복되는 현상도 보였다. 이번 선명한 비교 사진을 기준으로, 1015에서 도입했던 인쇄 커버의 강제 상단 음영·블러·확대/상향 보정을 제거한다.

## 원인과 수정

- `cassetteSoftTopScrollEdge`가 항상 시스템 soft edge를 표시했다. 이제 표시 여부 인자를 받고 기존 호출자의 기본 동작은 유지한다. 앨범 페이지는 Full-Bleed 커버가 상단에 있는 동안 효과를 숨긴다. 스크롤 거리가 기존 헤더 높이의 55%를 넘어 콘텐츠가 상단 바를 지나면 다시 표시하며, 위로 돌아오면 숨긴다. 카드형/데스크톱 페이지는 기존 효과를 유지한다. 스크롤 상태 갱신은 기존 경계 통과 시에만 수행한다.
- 인쇄형 커버에 중복 합성하던 별도의 블러와 검정 음영을 제거했다. 1.10배 확대와 0.15×너비 상향 이동도 제거하여 원본 인물과 문자를 보존한다. 사진형 커버의 크롭과 단색·질감 커버의 기존 구분은 유지한다.
- 상단 확장이 필요 없는 커버에서는 원본의 첫 4%를 다른 이미지 레이어와 섞던 처리도 생략한다.
- 원본 아래쪽 픽셀을 세로로 늘이던 처리를 제거했다. 캐시된 가장자리 색을 연장하고 원본 하단 8%를 해당 색으로 교차 페이드한다. 제목/아티스트/메타정보를 따라가는 기존 콘텐츠 페이드와 연결한다. 글자가 아래에 복제되거나 이미지 끝에서 가로 경계가 생기는 것을 방지한다.
- 상태 표시줄의 밝고 어두운 글자는 캐시된 상단 색상을 따른다. 별도의 그래픽 커버 강제 흰색 상태 표시줄 규칙은 제거했다. 떠 있는 내비게이션 버튼은 어두운 Glass와 흰색 아이콘을 사용하며, 하단 콘텐츠의 테마와 독립적으로 적용한다.
- 구형 OS의 고정 scrim에도 같은 표시 조건을 적용한다. 미니 플레이어, 음질 판정, Dolby 아이콘, Zoom 전환, 재생/다운로드 로직은 변경하지 않았다.

수정 파일: `FadedArtworkHero.swift`, `CassetteSpacing.swift`, `StatusBarScrim.swift`, `AlbumDetailView.swift`, `AlbumDetailView+Header.swift`, `ArtworkPresentationTests.swift`, 프로젝트 빌드 번호.
