# 앨범 몰입형 표시와 재생 화면 회전 — 1021

## 앨범 표시

- 사진형 커버를 내리던 0.32w 여백을 줄였다. 실제 앨범 페이지에서는 윈도우의 상단 안전 영역 높이만큼 색을 채우고 바로 아래에 커버를 둔다. 내비게이션 바 높이는 포함하지 않는다. 별도 윈도우가 없는 렌더링에서는 0.14w를 사용한다.
- 자동 판별 v8은 가로세로 비가 정사각형에서 벗어난 스캔과 공간적 연속성이 부족한 복잡한 이미지를 커버 카드로 표시한다. 원본 글자나 얼굴을 의미적으로 인식하는 모델은 아니며, 픽셀 구성에 따른 보수적 휴리스틱이다.
- 설정 → 음악의 `몰입형 앨범 아트워크`를 끄면 개별 앨범 설정보다 우선해 기존 카드 보기를 사용한다.
- 실행 후 라이브러리 인덱스를 확보하면 앨범 수 변경과 관계없이 준비 캐시를 확인한다. 구버전 분석과 현재 버전이지만 위/아래 색 등 필수 값이 없는 분석을 다시 만든다. 로컬 이미지가 없으면 네트워크 정책이 허용하는 비셀룰러 연결에서 분석용 썸네일을 보완한다. 실패한 항목은 다음 실행에서 다시 확인한다. 계정 전환 시 진행 중 결과를 다른 계정에 저장하지 않는다.

## 잠금화면

- iOS 26 이상의 지원 기기에 정사각형 정적 아트워크와 함께 3:4 `MPMediaItemAnimatedArtwork`를 전달한다. 600×800 미리보기와 동일한 이미지로 만든 2초 로컬 MP4를 사용한다. 원본 커버의 인물에 임의의 움직임을 추가하지 않는다.
- 현재 재생 세대와 설정을 다시 확인한 후 메타데이터에 합친다. 설정을 끄면 현재 곡의 세로 아트워크도 제거한다. 실제 확장 여부는 시스템이 결정한다.
- 구현 조건: [Apple의 animated artwork 문서](https://developer.apple.com/documentation/mediaplayer/providing-animated-artwork-for-media-items).

## 가로 재생 화면과 탐색

- 아이폰에서는 재생 중 화면이 표시되는 동안만 세로·가로 양쪽 방향을 허용한다. 다른 화면은 세로다. 아이패드는 기존 회전 지원을 유지한다.
- 닫기 애니메이션이 실제로 완료된 `fullScreenCover.onDismiss` 이후 120ms를 기다려 세로 방향을 요청한다. 대기 중 다시 열면 요청을 취소한다. 정해진 시간으로 닫기 완료를 추측하지 않는다.
- Apple Music으로 명시된 1번 스크린샷을 기준으로 커버를 줄이고, 오른쪽 제목과 진행 막대를 내렸다. 이전·재생·다음 버튼은 가용 너비에 맞춰 펼치며 작은 화면에서도 최소 조작 영역을 확보한다. 음질 배지는 가로 진행 막대 중앙에서 생략하고 남은 시간에는 마이너스를 붙인다. 하단 가사·출력·대기열은 양 끝과 중앙에 정렬한다. 출력 선택은 실제 iOS 선택기를 사용한다.
- 앨범 카드에서 진입하고 닫는 원래 줌 전환을 복원했다. 테마 소유권 갱신은 UIKit 전환 완료 후 다음 메인 큐에서 애니메이션 없는 트랜잭션으로 적용한다. 취소되거나 뒤집힌 전환의 오래된 콜백은 표시 세대 확인으로 무시한다. 전환 스냅샷을 정리하는 중 탭 테마 변경이 겹치는 경로를 줄인다.

## 검증

- macOS 렌더링·캐시 마이그레이션·잠금화면 로컬 MP4 생성/디코딩·테마 소유권 회귀 테스트 42회 통과(매개변수별 실행 포함). iOS 앱 및 테스트 타깃 빌드 성공. `git diff --check` 통과.
- 실제 iPhone의 회전·자동 세로 복귀·줌 전환 잔상과 잠금화면 확장 표시는 아직 기기에서 확인하지 못했다. iOS 전용 회전 테스트는 빌드 검증 대상으로 포함했다.
