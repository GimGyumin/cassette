# 일반 앨범 아트워크 프레젠테이션 — 1014

> 이후 전달된 Number Ones 비교는 사용자가 **2번이 Apple Music**이라고 명시했다. 이 문서의 기존 Number Ones 대상 판단은 새 비교로 대체한다. 상단 처리와 커버 배치의 추가 수정은 `2026-10-21-corrected-second-album-reference.md`의 1015 결과를 따른다.

## 사진에서 확인한 규칙

이번 일반 커버 3장과 앞서 전달된 앨범 비교 사진 7장을 다시 비교했다. 설정 화면과 빈 화면 오류 사진은 아트워크 색상 추정에 사용하지 않았다. 사용자가 두 번째 이미지가 Apple Music이라고 정정한 This Is It 비교도 반영했다. 측정 원본 이름·역할·좌표·색상은 `2026-10-21-general-album-reference-measurements.json`에 기록했다.

| 대상 | 하단 단색 배경 측정값 | 관찰 결과 |
| --- | --- | --- |
| Thriller | `#0C141C` | 일반 사진 커버도 전체 너비로 표시하고 짙은 남색으로 연결 |
| The Indispensable Collection | `#550C0C` | 콜라주의 모든 색을 평균내지 않고 넓은 붉은색 계열을 유지 |
| Number Ones | `#2E2E2E` | 흰 가장자리여도 하단 인쇄 제목이 있는 커버는 어두운 페이드 사용 |
| Thriller 40 | 약 `#2E2E2E` | 은색 질감은 유지하고 제목·정보 뒤에서 회색 캔버스로 연결 |
| This Is It | `#2B2F2E` | 밝은 상단과 별도로 하단은 녹색 기운이 약하게 남은 어두운 배경 |

Number Ones의 왼쪽 빈 여백은 화면 너비를 기준으로 y=0.70에서 흰색, 0.85에서 RGB 233, 1.00에서 164, 1.15에서 92, 1.30에서 53, 1.45에서 46이었다. 제목만의 짧은 마스크보다 제목 위에서 컨트롤까지 이어지는 넓은 합성이 관찰 결과와 잘 맞는다. 밝은 상단의 검은 상태 표시줄과 어두운 본문의 흰 텍스트도 별개의 대비 결정이다.

이것은 제공된 정지 화면에서 추론한 Cassette의 재현 규칙이다. Apple의 비공개 소스·메타데이터·원본 커버를 확보한 것은 아니며, 정확히 같은 내부 알고리즘이나 모든 앨범의 픽셀 일치를 확인한 것은 아니다. 서로 다른 커버 판본과 서버 이미지 해상도도 결과에 영향을 준다.

## 구현

- 분석 캐시 버전을 5로 올렸다. 기존 준비 서비스가 로컬 커버를 분석하고, 상세 페이지는 완료된 캐시만 읽는다. 스크롤·진입 중 분석을 추가하지 않았다.
- 가장자리 검사에 이미지 내부의 색상 분포와 공간적 연속성을 추가했다. 사진이나 넓은 색면이 있는 콜라주는 가장자리 변화가 커도 Faded Full-Bleed를 사용할 수 있다.
- 색조 24개 계열을 집계하며 바깥쪽·하단에 더 큰 가중치를 준다. 전체 가중 영역의 18% 이상을 차지하는 색 계열만 페이지 색 후보로 사용한다. 작은 로고·중앙의 피부색이 배경 전체를 쉽게 바꾸지 않도록 한다.
- 큰 색 계열은 어두운 명도와 읽기 쉬운 채도로 변환한다. 뚜렷한 색 계열이 없으면 중성 회색 또는 하단의 약한 색 기운을 유지한다. 기존 플레이어의 대표색 팔레트는 변경하지 않았다.
- 균일한 가장자리를 가진 이미지라도 하단에 넓은 인쇄 요소가 있으면 페이드를 선택한다. 좁은 중앙 인물이 있는 단색 Seamless는 원본 가장자리 색과 이미지 전체를 유지한다. 복잡하고 안정적인 배경이 없는 이미지는 Standard로 남길 수 있으며 수동 카드 선택도 유지한다.
- 인쇄 요소가 중심인 흰색 커버는 상단 확장으로 이미지가 아래로 밀리지 않도록 한다. 사진은 기존 smooth 비율, 질감은 기존 textured 비율을 사용한다. 커버 자체를 확대 크롭하지 않는다.
- 실제 제목 위 약 0.30×화면 너비에서 페이드가 시작되고 메타정보 아래 약 0.14×너비에서 배경색에 도달한다. 제목이 여러 줄이거나 접근성 글자가 커지면 실제 레이아웃 앵커를 따라간다. 페이드 아래는 불투명한 단색으로 연결한다.
- 메타정보와 음질 표시는 같은 보조 잉크를 사용한다. 대비 증가 설정에서는 불투명 잉크로 전환한다. 흰 재생 버튼의 글자·아이콘에는 대비를 확인한 페이지 색상을 사용한다.
- 기존 앨범 상세 화면을 수정했다. Zoom 내비게이션, 미니 플레이어·탭 바, 재생·다운로드 동작의 소유 구조는 유지한다.

수정 파일: `ArtworkEdgeAnalysis.swift`, `FadedArtworkHero.swift`, `CassetteSpacing.swift`, `CassetteColors.swift`, `AlbumDetailView.swift`, `AlbumDetailView+Header.swift`, `ArtworkPresentationTests.swift`, 프로젝트 빌드 번호.
