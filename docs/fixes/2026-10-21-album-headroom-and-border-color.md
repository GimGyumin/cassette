# 커버 상단 여백과 하단 테두리 색 — 1018

사용자가 아래로 잡아당긴 첫 스크린샷을 정상 표시 위치의 기준으로 사용했다. 새로고침 표시와 검은 빈 사각형은 재현 대상에 포함하지 않았다.

## 변경

- 사진형 Faded 커버와 제목·아티스트·재생 버튼을 화면 너비의 0.32배만큼 아래로 이동했다. 390pt 화면에서는 약 125pt다. 기존 사진 크롭 배율을 유지하므로 피사체를 세로로 찌그러뜨리지 않는다. 단색·인쇄·질감형의 개별 배치는 유지한다.
- 추가된 공간은 준비 단계에서 얻은 상단 가장자리 색으로 채운다. 원본 상단 4%와 부드럽게 합성한다. 이전처럼 이미지 윗부분을 늘이지 않으므로 Xscape 같은 글자가 반복되지 않는다.
- 가장자리 분석 v7은 위·아래 색을 별도로 저장한다. 페이지의 아래쪽 이미지 연결에는 전체 가장자리 평균 대신 실제 하단 가장자리 색을 전달한다.
- 하단 샘플의 65% 이상이 어두운 중성색 테두리(최대 채널 48 이하, 채널 차이 10 이하)이면 해당 테두리의 중앙값을 콘텐츠 배경으로 유지한다. 내부의 금색 도시·피부·붉은 의상이 검은 끝부분을 갈색 배경으로 바꾸지 않도록 한다. 앨범 이름에 따른 예외는 없다.
- 기존 분석 캐시는 준비 과정에서 v7으로 갱신한다. 앨범 페이지 진입이나 스크롤에서는 이미지 분석을 추가 실행하지 않는다. 미니 플레이어·탭 바·재생·다운로드는 기존 구조를 사용한다.

수정 파일: `ArtworkEdgeAnalysis.swift`, `FadedArtworkHero.swift`, `CassetteSpacing.swift`, `AlbumDetailView+Header.swift`, `ArtworkPresentationTests.swift`, 프로젝트 빌드 번호.

## 검증

- iOS Simulator 대상 빌드 성공, 빌드 경고·오류 없음.
- macOS `ArtworkPresentationTests` 27회 실행 모두 통과(매개변수별 실행 포함). 상단 여백의 불투명 색 채움, 제목 위치, 하단 연결, 검은 테두리 우선 선택, 캐시 직렬화를 확인했다.
- 합성 커버 렌더링을 확인했고 `git diff --check`를 통과했다.
- 실제 iPhone의 동일한 원본 커버로 전후 비교는 아직 하지 않았다.
