# 원본 커버 완료 판정과 캐시 삭제 수정

## 원인

- 저장된 전체 완료 플래그를 시작 시 그대로 신뢰했다.
- 변경 재확인이 coverArtId 변화만 검사해, ID가 같지만 파일이 없어지거나 손상된 경우를 놓쳤다.
- 기존 파일명만으로 다운로드 완료를 판정했다.
- 캐시 삭제/용량 집계는 @thumb, @hero만 포함하고, 실제 전체 커버 다운로드가 저장하는 @original-v1 파일은 제외했다.
- 캐시 삭제가 진행 중인 프리로더를 정지·드레인하지 않고 진행률 기록을 초기화했다.

## 수정

전체 ID 목록의 실제 원본 파일을 ImageIO로 검사하고 누락/손상 파일만 받는다. 백그라운드 작업의 기존 파일 재사용도 동일하게 검사한다. 완료 기록은 디스크 검사 대용으로 사용하지 않는다. 다운로드 성공과 선택적인 색상 준비를 분리하고, 전체 예정 작업 수가 완료되어야 완료 상태를 게시한다.

캐시 삭제는 원본 준비 파일을 포함하고 진행 중인 프리로더/백그라운드 작업을 먼저 드레인한다. 별도 표식 없는 오프라인 다운로드 커버는 보존한다. 삭제 후 전체 커버 자동 다운로드가 켜져 있으면 기존 Wi-Fi 정책에 따라 재확인한다. 저장 공간 표시에도 준비된 원본 커버를 포함한다.
