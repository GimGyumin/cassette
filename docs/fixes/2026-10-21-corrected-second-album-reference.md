# Number Ones 비교 대상 정정 — 1015

사용자가 최신 비교에서 2번(`860878ae…png`)을 Apple Music이라고 명시했다. 1번(`b547fc7f…png`)은 현재 결과로 비교한다. 앞선 Number Ones 기준을 그대로 반복하지 않고 이 구분을 측정 자료에 반영했다.

## 관찰과 변경

- 두 이미지의 인쇄 로고 최대 폭 비율은 약 1.11이다. 2번은 로고와 인물이 더 크고 위쪽에 있다. 인쇄 요소가 있는 `.graphic` 커버에 1.10배 배율과 화면 너비의 0.15만큼 위쪽 이동을 적용했다. 별도의 제목·아티스트 레이아웃은 이동하지 않는다.
- 2번 왼쪽 여백은 상단 RGB 151, y=0.20×너비에서 173, 0.30에서 227, 0.40에서 255다. 상단 약 0.40×너비의 제한된 흐림과 점진적인 검은 음영을 합성했다. 본문 페이드와 분리하며 원본 이미지·잠금 화면 아트워크에는 적용하지 않는다.
- 흐림은 기존 `PerformanceGovernor` 예산을 따른다. 메모리 압박 또는 저비용 chrome 정책에서는 음영만 유지한다. 동작·스크롤마다 이미지를 분석하지 않는다.
- 상단은 흰 상태 표시줄과 밝은 내비게이션 재질을 별도로 요청한다. 본문과 상위 미니 플레이어·탭 바의 다크 배경 설정은 유지한다.
- 하단 RGB는 두 사진 모두 약 45~46으로 큰 차이가 없어 기존 페이드 연결을 유지했다. 단색 Seamless 및 사진·질감 커버에는 새 인쇄 커버 배율과 상단 음영을 적용하지 않는다.

## 검증

수정 파일은 `FadedArtworkHero.swift`, `CassetteSpacing.swift`, `AlbumDetailView.swift`, `StatusBarScrim.swift`, `ArtworkPresentationTests.swift` 및 프로젝트 빌드 번호다.

- iOS Simulator arm64/x86_64 빌드 통과: `/tmp/cassette-1015-ios.log`.
- macOS 렌더링 회귀 테스트 통과: `/tmp/cassette-1015-tests.log`. 320/390/430pt에서 확대된 인물 폭, 올라간 인쇄 로고, 상단 음영과 중간 흰색 영역, 하단 불투명 캔버스를 검사한다. 흐림과 이미지 보간으로 달라진 경계를 배율로 오인하지 않도록 폭은 흐림 아래에서 중간 명도의 경계를 기준으로 측정한다.
- `/tmp/cassette-1015-printed-album.png` 합성 커버 렌더링을 시각적으로 확인했다. 파란색·녹색 위치 표시는 테스트 전용이다.
- 실제 iPhone에서 Liquid Glass·상태 표시줄·복귀 제스처까지 실행한 검증이나 Apple Music과의 완전한 픽셀 일치는 확인하지 않았다.
- `git diff --check` 통과. 최종 컴파일 경고·오류 없음.
