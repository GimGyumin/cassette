# TTML 가사 표현과 플레이어 기준 화면 조정

> 다음 날 실제 녹화에 근거한 조판·공백·배치 후속 조정은 [영상 비교 보고서](2026-10-26-lyrics-video-comparison.md)를 참고한다. 아래 수치와 검증은 당시 구현 기준이다.

## 반영 내용

- 사용자 제공 Apple Music 비교 사진의 비율에 맞춰 세로 가사 헤더 좌우 여백 32pt, 표지 72pt, 제목 17pt/아티스트 16pt로 조정했다. 즐겨찾기/더보기는 플레이어와 같은 심볼 크기를 쓴다.
- 하단 가사 선택 원은 40pt, 심볼은 18pt로 줄였다. 기존 54pt 터치 영역은 유지한다. 출력 장치 심볼·이름과 볼륨/하단 버튼 간격을 조정했다.
- 컨트롤이 숨겨졌을 때 세로 가사 패널이 홈 안전 영역 위까지 확장된다. 앞서 적용한 가로 화면 확장과 콘텐츠 알파 경계 페이드는 유지한다.
- `LyricGlyphRenderer`는 SwiftUI가 조판한 글리프를 그린다. 음절/단어의 시작·종료 시각에 따라 부드러운 그래디언트로 채우며, 별도의 시간 함수가 0.55–2.2pt 상승, 최대 1.014배 확대, 안쪽/바깥쪽 글로우, 긴 발음의 작은 움직임과 320ms 복귀를 계산한다. 타이밍을 스프링으로 지연하지 않는다.
- 단어 종료 후 잔광까지 끝나면 다시 그리지 않는다. 활성 텍스트만 60Hz 타임라인을 사용하고 저전력·열·메모리 압박에서는 30Hz로 낮춘다. 줄 추적은 기존 30/20Hz를 유지하며, 프레임 표시 시간은 최근 오디오 기반 샘플에서 최대 80ms까지만 보간한다. 정지·탐색 대기·숨김 상태에서는 보간을 중단한다.
- 비활성 가사에 중복 적용되던 낮은 불투명도를 정리하고 거리별 대비와 약한 흐림을 적용했다. 활성 글리프에는 행 전체 흐림을 적용하지 않는다.
- 일반 줄 전환은 짧은 스프링과 인접 행의 작은 강조 지연을 사용한다. 먼 탐색은 즉시 이동하고 가까운 탐색은 짧게 정착한다. 사용자가 스크롤하는 동안 자동 추적을 덮어쓰지 않으며 번역·발음 표시 변경 시 실제 행 높이로 재정렬한다.
- x-bg 블록은 높이를 미리 확보하고 자체 시간으로 채운다. 등장·퇴장으로 주변 줄 높이가 갑자기 바뀌는 현상을 줄였다. 기존 보컬별 정렬과 겹치는 독립 보컬 처리는 유지한다.
- 긴 토큰은 패널 너비 안에서 줄바꿈하며, 여러 시각적 줄을 차지해도 하나의 시간 진행도를 이어서 사용한다. 원문 음절 사이에 렌더러 여백이 추가되지 않는지 이미지로 검증했다.
- 간주 점은 간주 진행률에 따라 작게 움직이고 끝부분에서 사라진다. 별도 무한 반복 타이머를 만들지 않는다.
- 기존 TTML 파서·독립 배경 렌더러·가시성/발열 정책을 재사용했다. 화면 전체를 60Hz로 갱신하는 배경 효과를 추가하지 않았다.

## 검증

- macOS 빌드 및 iOS Simulator 범용 빌드 성공. 최종 iOS 로그: `/tmp/cassette-ttml-final-ios.log`.
- TTML 의미·타임라인·플레이어 렌더링·가사 표시: 43개 테스트 정의, 매개변수 포함 46회 실행 통과.
- 글리프·음절 간격·성능 예산·기존 가사 회귀: 25개 통과.
- 최종 패널 배치·시간 갱신·탐색·수동 스크롤·화면 복귀: 30개 통과.
- 세 테스트 실행 모두 실패/건너뜀/런타임 경고 없음. 중복 실행을 포함한 총 101회 검증이다.
- ImageRenderer로 한글/영문 진행 단계, 최종 잔광 제거, 원문 음절 경계와 긴 토큰 줄바꿈을 확인했다. `git diff --check` 통과.

## 기준과 한계

이 수치들은 제공된 사진과 요청된 표현을 토대로 조정한 Cassette의 값이다. Apple Music 내부 상수나 렌더러를 복제했다고 주장하지 않는다. 서로 다른 곡이 겹쳐 보이는 앱 전환기 사진만으로는 픽셀 단위 일치와 프레임별 동작을 확정할 수 없다. 동일 기기에서 같은 TTML을 재생한 화면 녹화 비교 및 Instruments 전력/GPU 측정은 수행하지 않았다.

관련 공개 자료: [SwiftUI TextRenderer](https://developer.apple.com/documentation/swiftui/textrenderer), [KaraokeText](https://github.com/WillSuo-Github/KaraokeText), [AMLL](https://github.com/amll-dev/applemusic-like-lyrics), [WWDC26 그래픽 효과](https://developer.apple.com/kr/videos/play/wwdc2026/322/). 외부 구현 소스를 복사하지 않고 기존 Cassette 구조에 적용했다.
