# 앨범 닫기 재표시·다른 앨범 링크·가로 음질 — 1022

- 기존 UIKit/SwiftUI 줌 진입·닫기 전환을 유지한다. 완료된 pop 이후 탐색 스택에서 제거된 앨범의 hosting view만 숨겨, SwiftUI의 뒤늦은 teardown/재렌더링 중 화면이 다시 노출되는 것을 방지한다. 다른 페이지를 위에 push했거나 인터랙티브 pop을 취소한 경우에는 숨기지 않는다. 스택에 남아 있는 화면과 시스템의 전환 레이어를 제거하지 않는다.
- 동일한 앨범 카드를 다시 누를 때 새 route UUID를 생성한다. 각 pushed route의 값은 유지하면서 이미 pop한 목적지 식별자의 재사용을 피한다.
- `아티스트의 다른 앨범 >` 제목은 텍스트 HStack뿐이던 상태에서 실제 `DetailNavigationLink`로 바뀌었다. 기존 앨범 헤더와 같은 아티스트 push 목적지로 이동하며, 44pt 이상 높이의 전체 제목 영역이 반응한다.
- 가로 진행 막대의 양쪽 시간 사이에도 기존 `AudioQualityClassifier` 결과를 전달한다. FLAC/무손실 트랙의 라벨을 생략하던 가로 조건을 제거했다. 전송 품질이나 트랙 메타데이터를 바꾸지 않는다.
- 회전은 기존 iOS 방향 정책과 UIKit 윈도우 회전을 사용한다. `viewWillTransition`과 실제 transition coordinator 완료 경계 동안 별도의 SwiftUI 장식/레이아웃 애니메이션을 억제하고 아트워크 배경의 장식 움직임을 잠시 정지한다. 배경 트리와 PlayerService/플레이어 모델은 회전 때문에 생성하지 않는다. 수동 `rotationEffect`, 각도별 확대, 스프링은 추가하지 않았다. 사용자가 보낸 분석의 약 0.3초는 참고치이며 시스템 회전 시간을 강제로 덮어쓰지 않는다.

검증: 204pt·380pt 영역에서 무손실 표시의 렌더링 검증을 포함한 macOS 테스트 10개 통과. iOS 앱·테스트 타깃 빌드 성공(경고·오류 없음). `git diff --check` 통과. UIKit 전용 pop 경계 테스트도 빌드 대상에 포함했다. 실제 iPhone에서 재표시 현상의 해소 여부와 제공 영상의 프레임별 일치는 아직 확인하지 못했다.
