# 계정 격리·오프라인 조회·다운로드 정리 수정 — 2026-10-13

요청한 세 항목을 수정했다. 기존 작업 트리는 보존했다. 이번 작업의 시작 상태와 변경 파일 해시는 `.derivedData-20261013-isolation/`에 보관했다.

## 계정 격리

- LibraryService의 클라이언트·상세·앨범 목록·즐겨찾기·아티스트 이름 인덱스는 계정 식별과 캐시 세대로 보호한다. 이전 응답은 새 계정의 캐시를 채우지 못하며, 이전 작업의 정리가 새 작업을 지우지 못한다.
- 클라이언트를 준비한 뒤 조회 작업을 등록하므로 최초 전체 앨범 조회의 요청 병합도 유지된다. 페이지가 500개보다 작아도 실제 반환 수만큼 다음 페이지를 요청하고, 새 항목이 없는 반복 페이지에서는 멈춘다.
- 라디오 캐시도 계정과 무효화 세대를 확인한다. 개인 믹스는 계정이 바뀌면 이전 목록을 이어받지 않고, 늦은 빌드 결과를 버린다.
- 새 고정 항목의 고유 키에 서버 UUID를 포함한다. 조회·개수 제한·해제·정렬·커버 변경은 활성 계정으로 제한한다. 기존 `{type}:{id}` 기록도 서버 필드로 읽으므로 고정 항목을 다시 만들 필요가 없다.
- 홈의 고정 항목·최근 다운로드·오프라인 곡 선택, 곡 목록의 계정 전환, 위젯 데이터와 커버 파일도 계정에 맞춰 처리한다.
- 디스크 커버는 서버 UUID와 원격 ID의 SHA-256 키로 저장하고, 메모리 캐시는 계정 세대를 포함한다. 슬래시·비 ASCII 문자가 들어간 ID도 저장 디렉터리 안에 머문다. 커버 요청의 URL·헤더는 같은 계정 컨텍스트를 사용한다.
- 기존 공용 커버는 오프라인 메타데이터가 소유 계정을 하나로 확인해 주는 경우에만 새 위치로 복사한다. 소유가 모호한 파일은 보존하되 다른 계정에서 표시하지 않는다. 이 경우 온라인에서 커버를 다시 받을 수 있다.
- 준비된 커버 탐색은 새 파일명을 인식한다. 커버 캐시 정리는 `@thumb`·`@hero` 파생 파일만 지우고 영구 원본을 보존한다.

## 오프라인 조회와 상태

- 재생목록 메타데이터를 짧은 동기 작업으로 추출하고, 관련 곡을 조회해 값으로 변환한다. 곡마다 전체 다운로드 목록을 다시 탐색하지 않는다.
- ID 별칭은 한 번의 백그라운드 인덱스 작업으로 묶어 조회한다. ID 사전으로 목록을 조립하며 원래 순서·중복 곡·현재 ID·이전 ID를 보존한다. 모델 객체나 컨텍스트는 `await` 너머로 전달하지 않는다.
- 파일이 없는 기록, 빈 파일, 저장된 크기와 다른 파일, 호환되지 않는 과거 다운믹스 파일은 다운로드 ID 집합과 오프라인 앨범·재생목록에서 제외한다. 크기 0인 기존 기록은 실제 파일이 비어 있지 않으면 계속 사용할 수 있다.
- 유효 파일을 기준으로 앨범·재생목록의 완료 수를 보정하며, 검증된 앨범 ID 별칭도 반영한다. 파일이 없는 기록 자체는 복구를 위해 보존한다.
- 전체 삭제가 조회와 겹치면 삭제 세대가 바뀐 이전 조회 결과를 반환하지 않는다.

## 전체 다운로드 삭제

DownloadService가 정리 작업을 소유한다. 새 전송 제출을 막고 기존 음원·앨범·재생목록·커버 작업을 취소해 기다린 뒤, 다운로드 디렉터리와 DownloadedTrack·DownloadedAlbum·DownloadedPlaylist를 정리한다. 곡이 없는 고아 재생목록 기록도 삭제한다. 저장 실패는 기록하며, 파일 가용성 확인은 남은 잘못된 기록을 재생 가능한 것으로 표시하지 않는다.

## 검증 결과와 범위

- macOS 전체 **1,069개 테스트 / 185개 스위트 통과**, 68.199초. [전체 로그](../.derivedData-20261013-isolation/full-tests-final.log)

- 1,000곡·1,002개 목록 항목의 통제된 메모리 데이터와 임시 파일 조회는 이번 실행들에서 약 **169–303ms**였다. 실기기·Release 수치나 동일 조건의 변경 전후 비교가 아니다.

- 전체 테스트 뒤 다운로드 집합 반환 직전에 삭제 세대를 한 번 더 확인하는 검사 1개를 추가했다. 이를 포함한 전체 테스트 재실행 요청은 **승인 단계에서 사용자 거절로 실행하지 못했다**. 위 1,069개 통과는 이 마지막 검사 추가 직전의 결과다.
